Como usar este laboratório

  1. Abra o painel 📊 dataLayer no canto da tela para ver cada evento.
  2. Crie um container no GTM e ative pela página Exercícios.
  3. Use o Preview (Tag Assistant) para testar tags GA4 e Google Ads.
  4. Teste campanhas com links como ?utm_source=google&gclid=TESTE123.

Por que medir?

Texto longo de propósito, para você praticar gatilhos de profundidade de rolagem (25%, 50%, 75%, 90%) e de visibilidade de elemento no banner logo abaixo.

Medir corretamente é a base de qualquer estratégia de mídia paga. Sem dados confiáveis, o algoritmo do Google Ads otimiza para o sinal errado, o GA4 mostra jornadas incompletas e as decisões de orçamento passam a ser baseadas em achismo.

Uma implementação de GTM bem-feita separa três camadas: a camada de dados (o que o site informa), as variáveis e acionadores (como o GTM interpreta) e as tags (para onde os dados vão). Este site entrega a primeira camada pronta, para você focar nas outras duas.

Com o Consent Mode v2, as tags do Google ajustam o comportamento conforme o consentimento do usuário. Com as conversões otimizadas, os dados primários (como e-mail) ajudam a recuperar conversões que seriam perdidas. Com o remarketing dinâmico, os itens visualizados viram anúncios personalizados.

Pratique cada um desses conceitos nos exercícios, valide no Tag Assistant e confira os relatórios em tempo real do GA4 e o diagnóstico de conversões do Google Ads.
